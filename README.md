# Películas para Marielena

Abre [index.html](index.html) en un navegador para usar la página. No hay instalación ni dependencias de JavaScript.

La lista contiene 23 películas y series. Los títulos originales vienen de las capturas de `General/`. Los episodios I, II y III de Star Wars, *Happy Feet* y *[REC]* usan las imágenes añadidas al proyecto. El apartado **Mis favoritas** muestra las 19 favoritas de quien preparó la lista.

Cada título empieza en **Por elegir**. Usa **No la he visto** para moverlo a **Pendientes** o **Ya la vi** para moverlo a **Ya vistas**. Los botones permiten cambiarlo de grupo después.

La selección se guarda automáticamente con `localStorage` en ese navegador y dispositivo. Si Marielena abre la página en otro navegador o borra los datos del sitio, empezará con la lista original. Para compartir una selección entre dispositivos haría falta agregar almacenamiento en línea.
